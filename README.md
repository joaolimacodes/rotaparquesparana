# Parques e Rotas do Paraná · Invest Paraná

Apresentação em HTML (16:9, 1920×1080, escala automática para qualquer tela).

## Publicar no GitHub Pages

1. Crie um repositório e envie **todo o conteúdo desta pasta** (`index.html`, `assets/`, `fonts/`, `.nojekyll`) para a raiz.
2. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta `/ (root)`. Salve.
3. Em 1–2 minutos o link fica disponível em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.

## Navegação

| Ação | Teclas |
| --- | --- |
| Avançar | → · ↓ · Espaço · Enter · PageDown · clique na tela · deslizar no celular |
| Voltar | ← · ↑ · PageUp · clique no quarto esquerdo da tela |
| Tela cheia | **F** ou botão "Tela cheia" (canto inferior direito, aparece ao passar o mouse) |
| Primeiro / último slide | Home / End |
| Ir direto a um slide | adicione `#s1` … `#s7` ao link |

O slide 6 (quatro rotas) avança região por região antes de passar ao próximo slide.

## Testar localmente

Abra um terminal nesta pasta e rode `python -m http.server 8000`, depois acesse `http://localhost:8000`.
